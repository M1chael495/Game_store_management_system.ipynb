# Game Store Management System

A Python-based management system to manage game store data through a graphical user interface and database.

## Features

* Graphical user interface for interacting with the system
* Game and customer data management
* Add, update and delete records
* Search and retrieve game information
* Database integration
* Input validation

## Technologies

* Python
* Jupyter Notebook / Google Colab
* ipywidgets
* matplotlib

## System Design
Users can perform database operations through the interface without directly writing SQL queries.


## How to Run

Open `game_store_management_system.ipynb` in Jupyter Notebook or Google Colab and run the cells in order.
